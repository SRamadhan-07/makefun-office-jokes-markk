# One-Line Office Jokes — office-jokes-markk

A small Python program that writes a single-line joke about office life to `/output/entry.txt`. The joke turns on a familiar meeting detail — the supposedly brief "quick sync" that never ends — and saves its punchline for the final words.

## Run

```bash
python3 main.py
```

This creates `/output/entry.txt` containing the one-line entry: a joke about a "quick sync" meeting that grew a recurring calendar invite of its own.
